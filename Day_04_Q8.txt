Q8 - Sum of First n Natural Numbers

QUESTION:
Write a program to find and display the sum of the first n natural numbers.

CODE:
#include <stdio.h>

int main()
{
    int n, sum;

    printf("Enter n: ");
    scanf("%d", &n);

    sum = n * (n + 1) / 2;

    printf("Sum = %d\n", sum);

    return 0;
}

OUTPUT:
Enter n: 5
Sum = 15

SAMPLE TEST CASE 2:
Enter n: 10
Sum = 55
